# Telegram icon asset

`telegram-icon.png` is a PNG export of `Logo.svg` from Telegram's official logo
archive. The vector geometry and colors are preserved. A 128-color PNG palette
keeps the file within the ChatGPT upload form's 10 KiB limit.

- Source guidance: [Telegram Tour screenshots](https://telegram.org/tour/screenshots)
- Download: [Telegram logo archive](https://telegram.org/file/464001088/1/bI7AJLo7oX4.287931.zip/374fe3b0a59dc60005)
- Original archive filename: `Logo.svg`
- Dimensions: 256 × 256 pixels
- Size: 4,581 bytes
- SHA-256: `d0e51db029112a0617ee25103e5a13122983647c2c98dece2b851fe9595da108`

Telegram's guidance permits its logo in illustrations and buttons, but says it must not imply an official Telegram project.
